### Bonjour Menu

> Menu Bar app that browses bonjour for _http services and shows them. Also provides them as Spotlight Info while running so siri can find them.

Requirements: macOS 27

Download: [Bonjour Menu v1.1](https://github.com/monkeydom/apps/releases/download/release%2FBonjourMenu-v1.1/BonjourMenu-v1.1.dmg)
